# Advent of Code 2024

My solutions for [aoc2024](https://adventofcode.com/2024) written in TypeScript

## Running

Install dependencies:

```bash
npm install
```

Compile TypeScript:

```bash
npm run serve
```

Run:

```bash
npm run start
```

## Testing

To run unit tests:

```bash
npm run test
```

To generate coverage report:

```bash
npm run coverage
```
